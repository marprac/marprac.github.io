# Marko Praček — Personal portfolio

A minimal, dark personal website for GitHub Pages. Plain HTML and CSS with a small optional JavaScript enhancement, no dependencies or build step. All navigation, expandable research/project notes, and hover effects work without JavaScript. Fonts and artwork are local; the page makes no third-party requests.

The personal portfolio is published at [marprac.github.io](https://marprac.github.io). The ISP Study Room and all its course materials, libraries, and maintenance scripts are preserved in [`archive/isp/`](archive/isp/README.md), accessible at [marprac.github.io/archive/isp/](https://marprac.github.io/archive/isp/). The original portfolio backup remains in `archive/personal/`.

To preview both pages, run `python -m http.server 8080 --bind 127.0.0.1` from the repository root. Open `http://127.0.0.1:8080/` for the portfolio or `http://127.0.0.1:8080/archive/isp/` for the study room. Publish through the existing GitHub Pages deployment by pushing to `main`.
